# Tasklist

A small task manager used as the built-in demo for
[claimcov](../../README.md).

Two of the features below are deliberately not implemented. The point of the
demo is that the document claims them anyway, and `claimcov` proves which claims
survive.

## Features

- Create tasks with a title and a tag
- Mark tasks as complete
- Filter tasks by tag
- Export all tasks to CSV
- Sign in with Google

## Usage

Open the page, type a title, pick a tag, and press **Add task**. The list updates
immediately. Change the filter to narrow the list to one tag.

## Notes

This demo is intentionally incomplete. Anything below the fold in the feature
list is a claim without an implementation.
